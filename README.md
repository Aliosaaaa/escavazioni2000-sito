# Escavazioni 2000 — sito

Sito statico dell'impresa **Escavazioni 2000 di Bertocci Luigi e figli** — Pescia (PT).
**Online su https://www.escavazioni2000.it dal 31 agosto 2026**, servito da GitHub Pages.

## Le pagine .html non si modificano a mano

Sono generate tutte da un unico script, che per scelta **non sta in questo repo**:
questo repo e' pubblico e GitHub Pages servirebbe il sorgente insieme al sito.
Il generatore vive nel repo privato di lavoro.

Una correzione fatta direttamente su un file .html sparisce alla prima rigenerazione.

## File da non cancellare

- `CNAME` — tiene il dominio su GitHub Pages.
- `google26afaa2b1444c308.html` — e' la verifica di Google Search Console.
- `.nojekyll` — dice a Pages di servire i file cosi' come sono.
